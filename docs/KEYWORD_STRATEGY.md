# Purpose

This document defines the official keyword strategy for ShareTextQR.

Every indexable page must follow this document.

Only approved keywords may be used during implementation.

If this document conflicts with implementation, this document takes priority.

---

# SEO Rules

Every page must define:

• Primary Keyword

• Supporting Keywords

• URL

• SEO Title

• Meta Description

• H1

• Hero Tagline

• Schema

One page must target one Primary Keyword only.

Keyword stuffing is prohibited.
